# ⚡ Hogwarts Acceptance Letter — Digital Birthday Invitation

An interactive, 3D animated Harry Potter-themed digital invitation web page. Designed to be hosted for free on GitHub Pages and sent to guests via text message with custom personalized URL links.

---

## 📜 Features

* **3D Animated Hogwarts Envelope**:

  * Interactive flip on tap/click to reveal the Hogwarts wax seal (`H`).
  * Smooth unsealing and opening sequence revealing the Hogwarts acceptance letter.

  * Displays the official Hogwarts Crest and header.

  * Built-in bottom toolbar allowing the host to enter any guest's name and automatically copy a personalized link to text to them.

## 🚀 How to Host on GitHub Pages

1. **Create a GitHub Repository**:
   * Go to [GitHub.com](https://github.com) and click **New Repository**.
   * Name your repository (e.g., `hogwarts-invite`).
   * Set it to **Public**.

2. **Add `index.html`**:
   * Create a file named `index.html` in the root of your repository.
   * Paste the invitation HTML code into `index.html` and commit the file.

3. **Enable GitHub Pages**:
   * Go to your repository's **Settings** tab.
   * Click **Pages** in the left sidebar menu under *Code and automation*.
   * Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   * Set the branch to `main` (or `master`) and folder to `/ (root)`.
   * Click **Save**.

4. **Get Your Live URL**:
   * Wait 1–2 minutes for GitHub to build the page.
   * Your base web link will be live at:
     `https://<your-github-username>.github.io/<repository-name>/`

## ✉️ Personalizing & Texting Invite Links to Guests

You can personalize the letter and address on the envelope for every guest using URL parameters (`?first=Name&last=Name`).

### Method 1: Use the Built-in Link Generator
1. Open your live hosted web page URL in your browser.
2. Scroll to the bottom drawer **Personalize for a Guest**.
3. Type the guest's name (e.g., `Hermione Granger`) and click **Copy Link**.
4. Paste the URL directly into your text message!

### Method 2: Create Links Manually
Append `?first=Firstname&last=Lastname` to the end of your GitHub Pages URL:

* **Hermione Granger**:
  `https://<your-username>.github.io/<repo-name>/?first=Hermione&last=Granger`
* **Ron Weasley**:
  `https://<your-username>.github.io/<repo-name>/?first=Ron&last=Weasley`
* **Harry**:
  `https://<your-username>.github.io/<repo-name>/?first=Harry`
